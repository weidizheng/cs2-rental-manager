# 发布说明

## v3.1.5

- 无法唯一关联时，导入确认弹窗新增“新建资产并关联”。它会预填订单的饰品名、磨损、相位、日租和当前出租状态，并要求用户在资产表单中确认买入成本等归属信息。
- “未关联订单”窗口新增“为选中订单新建资产”，可将此前选择暂不关联的订单补建为资产后立即关联。

## v3.1.4

- 选择“暂不关联（仍导入此订单）”现在是可持久化的明确决定：订单仍会写入数据库，重复导入也不会自动重新关联到资产。
- 资产总览新增“未关联订单”入口，可查看这些已保存订单的订单号、饰品、磨损、起止时间与定价方式；导入完成提示也会显示未关联数量。
- 资产平台已移除“悠悠有品”。升级会将旧资产的平台分类留空，同时保留原来的“CD冷却”或“在库”等资产状态；历史订单的平台字段不会改写。

## v3.1.3

- 资产与出租订单的磨损统一保存为 8 位小数，并使用十进制“四舍五入（5 入）”。例如 `0.0207196157425642` 会记录为 `0.02071962`，`0.350518137216568` 与 `0.3505181372` 都会记录为 `0.35051814`。
- 首次升级时自动创建 `app.db.pre-float-normalization-时间.bak`，随后统一旧记录格式。
- 若“标准化名称 + 8 位磨损”相同，系统将归并为同一资产：优先保留 C5GAME 资产及其稳定 `asset_id`，历史订单全部改关联到该资产；被归并资产的平台会写入保留资产备注，订单的平台字段保持原样可追溯。

## v3.1.2

- 修复 IGXE 展示磨损少于库存保存精度时无法自动关联的问题。例如页面的 `0.3505181372` 可安全匹配库存中的 `0.350518137216568`。
- 不再要求在预览表内手工填写缺失信息。点击“确认导入”后，缺失的 IGXE 定价方式会弹窗询问；确实无法唯一关联资产时，也会弹出较大的资产选择框，并可选择“暂不关联”继续导入。
- 移除导入预览左侧无意义的行号栏，并为表格角标/表头补齐深色主题，避免出现灰白色块。

## v3.1.1

### 剪贴板订单导入

- 导入预览窗口加大，`定价方式` 与 `关联资产` 两列使用固定的可见宽度。
- 关联资产时，系统依次使用已确认的本地资产 ID、稳定资产标识、唯一库存磨损，以及已有资产历史中唯一的已关联磨损。
- 历史关联刻意不按平台限制。购买平台和出租平台可以不同；导入订单的平台以本次导入为准，资产的购买平台不会被订单导入覆盖。
- 若同一磨损对应多个候选资产，系统不自动猜测，仍在预览中保留人工选择。

### 本地饰品映射资源

- 英文和中文映射源文件位于 `assets/schema-source/`，并由 PyInstaller 内置到 EXE。
- `private-data/` 只保留每台设备自己的运行数据和可重建索引 `cs2_items_schema.json`，不再存放这两份共享资源。

### Google Drive 手动同步

1. 点击“生成加密同步包”，设置至少 8 位口令；文件会写入 `private-data/cloud-sync/outbox/CS2RentalSync.cs2sync`。
2. 将该文件上传到自己的 Google Drive；内容使用 AES-256-GCM 加密，口令不会保存在程序或包内。
3. 在另一台电脑下载文件后，点击“导入下载的同步包”并输入同一口令。
4. 程序会先生成本机加密备份，再按“平台 + 订单号”合并订单、按分类和观察品标识合并行情收藏；本机独有数据不会删除。

同步包包含出租订单、行情收藏和 API 配置（包括加密包内的 API 凭据）。它不包含饰品图片、浏览器登录状态、SQLite 主库、原始中英文映射资源或可重建的行情缓存。内置映射资源随 EXE 发布，无需上传到云盘。

## 打包与发布

在项目根目录运行 `build_exe.bat`。脚本会编译、运行完整单元测试，并在 `release/CS2租赁管理.exe` 生成单文件发布包。由于包含离线中英文映射资源，发布包体积会比以前增加约 70MB；应把 EXE 作为 GitHub Release 附件上传，而不是提交进 Git 仓库。
